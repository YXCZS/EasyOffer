## Why

当前答题页只能向前作答，用户无法回看上一题的选择和解析；不同页面的返回控件位置、尺寸和形状也不一致，增加了操作成本。个人页的“修改昵称”与用户身份信息分离，退出登录后还保留了多余的“返回答题”按钮，需要统一交互层级并精简页面。

## What Changes

- 在答题过程中增加“上一题”操作，允许回看已经作答的题目、原选择、正误结果和解析，同时保持断点续答位置不倒退。
- 将答题页底部操作区改为稳定的前后题导航布局；第一题禁用上一题，回看历史题时可继续向前返回当前答题位置。
- 统一需要自定义返回控件的二级页面：返回控件位于顶部左侧安全区内，使用相同的图标、点击区域、尺寸、形状和交互状态。
- 将个人页“修改昵称”移动到昵称信息附近，使头像、昵称、修改操作和 XP 形成一个清晰的用户信息区；编辑状态仍在同一区域完成输入、保存和取消。
- 删除个人页退出登录按钮下方的“返回答题”按钮，保留底部 Tab 导航作为“答题”和“我的”之间的唯一主导航。
- 不修改后端接口、题目生成、答案判定、报告生成、底部 Tab 结构或个人资料数据模型。

## Capabilities

### New Capabilities

- `quiz-question-navigation`: 规定答题过程中上一题回看、前向返回、答案只读展示和断点进度保护行为。
- `consistent-page-controls`: 规定二级页面返回控件和底部答题操作按钮的统一布局、尺寸、形状及状态。
- `user-system`: 调整个人页昵称编辑入口和退出区域的用户可见行为，移除多余的“返回答题”按钮。

## Impact

- 主要影响 `frontend/src/pages/quiz/`、`frontend/src/pages/profile/`、相关二级页面顶部导航样式，以及必要的共享样式或轻量组件。
- 答题回看使用页面级浏览索引，不降低 Zustand 会话中的最远答题进度，也不向后端保存倒退的 `current_index`。
- 不新增后端 API、数据库字段或第三方依赖。
- 需要回归验证增量出题轮询、答案保存、未完成练习恢复、报告生成、头像编辑、昵称修改、退出登录和底部 Tab 导航。
