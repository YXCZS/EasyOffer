## Why

当前游客无法使用异步出题流程，导致未登录用户无法体验 EasyOffer 的核心价值；同时现有联网与个人知识库选择主要依赖后端规则，尚未真正由 Agent 根据主题、知识库命中质量和信息新鲜度进行工具路由。需要在不破坏知识库专属模式、增量出题和降级能力的前提下，补齐游客出题能力并建立可控、可观测的 Agentic RAG 路由。

## What Changes

- 允许游客创建普通主题的异步出题任务，并继续限制游客访问个人知识库、历史记录和需要登录的用户能力。
- 新增结构化 Agentic RAG 路由决策：由 DeepSeek Agent 在受限工具预算内判断使用基础模型、Chroma 个人知识库、Tavily Search、Tavily Extract 或组合路径。
- 保留并强化硬性优先级：指定 `document_id` 时只能使用指定文档；HTTP/HTTPS URL 只能走 Extract；普通关键词主题才能走 Query Expansion + Search。
- Agent 只能输出结构化路由计划，后端负责校验工具白名单、调用次数、超时、权限和降级，不允许无限自主循环或执行网页指令。
- 为游客联网搜索增加频率、并发、每日额度和上下文长度限制，避免未登录访问造成成本失控。
- 让 Agent 路由失败、工具失败、证据不足和模型超时都回退到基础模型，不能阻塞首题生成或污染未完成答题记录。
- 保持现有底部“答题/我的”导航、知识库专属答题、增量逐题生成、答题恢复和报告流程不变。
- 不新增搜索时效选择器，不引入新的向量数据库，不允许游客读取或写入其他用户的知识库数据。

## Capabilities

### New Capabilities

- `guest-quiz-generation`: 游客创建普通主题异步出题任务、访问限制、联网额度和降级行为。
- `agentic-rag-routing`: 结构化 Agent 路由 Chroma、Tavily Search、Tavily Extract 与基础模型，并保证工具边界、证据质量和可观测性。

### Modified Capabilities

无。当前仓库没有已发布的 `openspec/specs/` 主规格文件；本变更新增能力规格，后续可在归档时同步到主规格。

## Impact

- 后端游客任务创建与鉴权边界：生成任务 API、增量生成服务、任务快照和请求限流。
- 后端研究路由：Agent 状态模型、工具适配器、Chroma/Tavily 调用、证据过滤、缓存和日志元数据。
- DeepSeek Prompt 与结构化输出校验；需要保留 Tavily、Chroma、MySQL 和现有增量任务数据结构兼容性。
- 前端生成页只需适配游客任务状态和额度错误提示，不改变现有答题页与报告页布局。
- 测试：游客/登录用户权限、Agent 路由决策、工具失败降级、成本限制、增量首题和微信小程序构建回归。
