## 2. 来源清洗与证据包

- [ ] 2.1 新增来源和证据包领域模型，包含 URL、标题、站点、版本/发布时间、抓取时间、摘要、来源等级、时效状态和内容哈希；为字段约束编写单元测试。
- [ ] 2.2 实现 URL 规范化、追踪参数清理、正文哈希去重、独立站点识别和来源等级评分；测试重复转载、不可访问页面、SEO 噪声和官方来源优先级。
- [ ] 2.3 实现最低证据门槛和版本冲突检测，验证普通主题至少需要两个独立来源、版本敏感主题优先需要权威来源、来源不足与来源冲突会产生不同状态。

## 3. 题组模型与证据约束生成链

- [ ] 3.1 扩展 `Question`、`Quiz` 和生成响应模型，增加可选来源引用、来源清单、检索时间、时效状态、AI 标识和研究模式字段；验证旧题组 JSON 仍能通过模型校验。
- [ ] 3.2 重构题目生成服务为“检索 -> 证据判断 -> 出题”流程，检索前的模型判断只能作为软信号；验证新术语不会被固定词表直接拒绝，非技术输入仍返回现有范围错误。
- [ ] 3.3 编写 `quiz-grounded-v1` 主题判断和出题 Prompt，使用 `ChatPromptTemplate`、DeepSeek `ChatOpenAI` 和结构化 Pydantic 输出；验证 Prompt 包含岗位、难度、证据摘要和来源 ID，并禁止证据外事实。
- [ ] 3.4 实现确定性题目校验和独立质量校验，检查答案唯一性、题目重复、版本前提、来源引用和证据支持；mock 校验失败时验证最多一次修正生成，仍失败则不下发题组。
- [ ] 3.5 实现 JSON Object 降级解析和统一错误码（主题歧义、来源不足、搜索不可用、来源冲突、证据校验失败），验证错误响应继续符合 `{code, message, data}` 格式。
