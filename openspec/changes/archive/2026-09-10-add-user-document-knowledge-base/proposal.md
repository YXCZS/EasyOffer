## Why

用户目前只能依赖模型内置知识或联网搜索，无法把自己的课程讲义、项目文档、公司面试资料纳入练习范围。为提高题目和报告对用户实际材料的可信度，需要支持用户上传文档并建立个人知识库，再由 Agent 根据问题决定使用个人知识库、联网搜索或两者组合。

## What Changes

- 新增“我的知识库”能力，支持用户上传 PDF、Word、Markdown 文档并查看处理状态。
- 对上传文档执行解析、清洗、分块、Embedding，按用户隔离后持久化到 Chroma。
- 支持查看文档列表、删除文档、删除文档产生的向量数据，并显示失败原因及重试入口。
- 在生成题目和分析报告前增加 Agentic RAG 编排：由 Agent 判断检索个人知识库、Tavily 搜索/网页提取，或同时使用两者。
- 将检索到的内容、来源和置信信息注入现有 DeepSeek Prompt，保留原有无知识库时的生成流程作为降级路径。
- 增加来源标识和日志，区分“个人知识库”“联网资料”“基础模型”三类生成依据。
- 保持现有“答题 / 我的”底部导航、题目生成、答题、报告和断点续答流程兼容，不强制用户上传文档。
- 不在本变更中实现多用户共享知识库、团队协作、OCR 扫描图片、音视频解析或知识库导出。

## Capabilities

### New Capabilities

- `user-document-knowledge-base`: 用户上传文档、个人知识库隔离、文档处理状态和 Chroma 向量生命周期管理。
- `agentic-rag-retrieval`: 在题目和报告生成前由 Agent 动态选择个人知识库检索与 Tavily 搜索/提取，并提供证据注入和失败降级。

### Modified Capabilities

无。现有题目生成、答题、报告和用户系统的外部行为保持兼容，本变更通过可选上下文增强生成质量。

## Impact

- 前端：Taro “我的”页面新增知识库入口、文档上传、处理状态、删除/重试交互；答题首页或生成状态页增加当前知识来源提示。
- 后端：新增文档上传与管理 API、异步/后台文档处理服务、Chroma collection 管理、检索编排服务和生成上下文扩展。
- 数据库与存储：MySQL 保存文档元数据、处理状态、用户归属和错误信息；本地或对象存储保存原文件；Chroma 使用持久化目录并按用户 collection 或 metadata 过滤隔离。
- AI 与依赖：LangChain 文档加载器、文本分块、Embedding、Chroma 集成、Agent 工具调用；复用 DeepSeek、Tavily Search/Extract。
- 配置与运维：新增上传大小/格式、Embedding 模型、Chroma 持久化目录、处理并发和检索 Top-K 等配置；需要补充数据清理和备份策略。
- 测试：增加文档解析、用户隔离、幂等删除、向量写入、Agent 路由、搜索失败降级和现有核心流程回归测试。
