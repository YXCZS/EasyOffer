## Why

当前题目解析完全依赖纯文本，算法流程、系统协作和抽象技术概念缺少直观的视觉辅助。需要在不阻塞现有逐题出题和答题流程的前提下，根据解析内容按需生成配图，并将图片可靠地保存到腾讯云 COS，避免生图服务返回的临时链接失效。

## What Changes

- 扩展题目解析结构：由 DeepSeek 在生成题目和文字解析的同时判断是否适合配图，并输出受约束的图片提示词和图片说明。
- 新增百炼图片生成能力，使用可配置的 Qwen Image 模型按题目解析生成技术学习配图；模型名、超时、尺寸和单轮最多生成数量通过配置管理。
- 在闯关设置中增加“生成图片”开关，用户主动开启后才产生图片调用和费用；默认关闭。
- 将生图返回的临时 URL 或 base64 下载/解码后上传腾讯云 COS，仅向业务数据保存稳定的资源标识和 COS 对象路径。
- 新增图片资源任务状态，文字题目先进入答题任务，图片在后台生成和上传；前端能够展示 pending、ready、failed 状态。
- 在答题提交后的解析区域展示已持久化的图片和替代文本；图片生成、下载、上传或加载失败时自动降级为纯文字解析，不影响题目、评分和报告。
- 历史记录详情回看题目解析时展示已保存的配图。
- 为图片任务增加幂等、超时、有限重试、大小/格式校验和日志记录，避免重复扣费和临时链接泄漏。
- 保持现有“答题”和“我的”底部导航、题目生成、增量轮询、答题进度和报告流程不变。

## Capabilities

### New Capabilities

- `quiz-explanation-visual-assets`: 管理题目解析配图的 AI 判断、生图任务、COS 持久化、状态同步、前端展示和失败降级。

### Modified Capabilities

- 无

## Impact

- 后端题目模型、DeepSeek 题目 Prompt、增量生成服务、任务快照和答题解析接口。
- 新增百炼图片 API 客户端、腾讯云 `cos-python-sdk-v5` 依赖、COS 配置和图片任务持久化表。
- 前端题目类型定义、答题解析区域和图片加载/失败状态 UI。
- 需要配置百炼 API Key、图片模型、512×512 尺寸、COS SecretId/SecretKey、Region、Bucket 和公开访问域名；图片对象按产品决定配置为公开可访问。
- 需要新增后端单元测试，并通过前端 typecheck、微信小程序构建和关键答题流程验证。
