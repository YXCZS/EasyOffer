# quiz-data-source-routing Specification

## Purpose
为不同用户入口建立清晰、可验证且互不越权的题目知识来源边界，避免普通答题隐式读取个人知识库，并让游客获得低成本、可预测的基础模型体验。

## Requirements

### Requirement: 游客普通答题只使用基础模型

系统 MUST 将未登录用户从普通答题首页发起的生成任务限制为基础模型路径，不得调用个人知识库、Chroma、Tavily Search、Tavily Extract、查询扩展或搜索结果过滤工具。

#### Scenario: 游客生成普通题目
- **WHEN** 游客从答题首页输入主题并点击生成
- **THEN** 任务使用基础模型逐题生成，并且生成快照中的来源标记为基础模型

#### Scenario: 游客请求携带个人文档
- **WHEN** 未登录请求包含 `document_id`
- **THEN** 系统拒绝该请求并提示登录后使用知识库，不得降级为读取该文档

### Requirement: 登录用户普通答题不得自动读取个人知识库

系统 MUST 将登录用户从普通答题首页发起的任务视为普通主题答题，不得仅因为存在 `user_id` 就执行 Chroma 检索或个人知识库检索。Agent 仅可在基础模型、关键词联网搜索和网址内容提取之间选择。

#### Scenario: 登录用户输入普通技术主题
- **WHEN** 登录用户未从知识库页面指定文档而输入一个普通技术主题
- **THEN** 系统不读取任何个人文档，并根据路由结果使用基础模型或联网搜索

#### Scenario: 登录用户输入网址
- **WHEN** 登录用户输入合法 HTTP 或 HTTPS 网址且未指定文档
- **THEN** 系统使用网页内容提取路径，不执行个人知识库检索

### Requirement: 知识库入口只使用指定文档

系统 MUST 只允许登录用户通过知识库文档的“开始答题”入口创建知识库专属任务。该任务 MUST 只检索指定 `document_id` 的 Chroma 内容，禁止 Tavily 和其他文档内容进入题目证据。

#### Scenario: 从已就绪文档开始答题
- **WHEN** 登录用户对状态为 ready 的文档点击“开始答题”
- **THEN** 系统创建 knowledge-only 任务，检索范围限定为该文档，并在快照中标记 `route=document_only`

#### Scenario: 文档内容不足
- **WHEN** 指定文档没有足够的有效切片生成当前题目
- **THEN** 系统允许基础模型补充生成，但不得调用公共网络或其他文档，并在来源元数据中标记基础模型兜底

### Requirement: 数据源失败必须可控降级

系统 MUST 捕获路由、Chroma、Tavily 或证据过滤失败，并按入口边界降级；普通登录任务可降级到基础模型，知识库专属任务可降级到基础模型但不得越过文档边界，游客任务始终保持基础模型路径。

#### Scenario: 普通登录用户联网搜索失败
- **WHEN** Agent 已选择联网搜索但搜索或过滤超时/报错
- **THEN** 任务记录失败原因并使用基础模型继续生成，不将任务标记为不可恢复失败

#### Scenario: 知识库检索失败
- **WHEN** 指定文档的 Chroma 检索不可用
- **THEN** 任务使用基础模型继续生成，并明确标记未使用个人文档，不调用 Tavily
